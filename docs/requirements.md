# Requirements

| Item | Requirement | Notes |
|---|---|---|
| Work envelope | 250 x 250 mm in X and Y | Z travel 150 mm, about 180–200 mm clearance from table to spindle nose (D-09) |
| Materials | Aluminium, brass, steel | Small, high-precision parts |
| Part accuracy | ±0.02 mm | Reached with C7 screws plus LinuxCNC screw compensation (D-10) |
| Layout | Fixed gantry, moving table (Y) | Spindle moves in X and Z on the gantry |
| Frame | Epoxy granite, cast DIY at home | |
| Spindle | Jianken 2.2 kW ATC, ISO20 | About 24,000 rpm. Low torque at low rpm, so steel needs light cuts and small tools |
| Tool changer | 8 tools, rack behind the gantry | Rack slides in low, through the table opening (see D-06) |
| Drives | Closed-loop steppers | |
| Control | LinuxCNC on Mesa hardware | Board to be chosen |
| Coolant | Mist / MQL | |
| Enclosure | Full enclosure | Also keeps chips out of the rack |
| Air | Existing compressor | ATC tool release needs about 6 bar or more |
| Site | Garage, on a heavy stand built by the owner | Frame mass budget about 200–350 kg |
| Budget | **Phase 1 ≤ £4,000** (frame, motion, electronics, ER20 spindle). Phases 2 (ATC spindle, air, enclosure) and 3 (tool rack) budgeted later | D-66, D-68 |
