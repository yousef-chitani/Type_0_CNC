# Type 0 CNC

A DIY 3-axis CNC mill: fixed gantry and moving table, with a cast epoxy granite (EG) frame and an 8-tool changer.
Inspired by [Bootstrap Bill](https://github.com/Expatria-Technologies/bootstrap-bill-mill).

The project is in planning. Decisions are made one round of questions at a time.

- [Requirements](docs/requirements.md): what the machine must do
- [Decision log](docs/decisions.md): what was decided, and why
- [Open questions](docs/open-questions.md): what's still to decide
- [EG moulds](docs/eg-moulds.md): mould diagrams, cores, fabrication and demoulding (draft)
- [Epoxy options](docs/epoxy-options.md): UK resin comparison
- [I/O list](docs/io-list.md): signals the control system must handle (draft)
- [Bill of materials](docs/bom.md): parts list, confirmed prices only
