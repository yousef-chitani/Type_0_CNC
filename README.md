# Type 0 CNC

A DIY 3-axis CNC mill: moving gantry on a fixed table in one cast epoxy granite (EG) tub (D-137), steel gantry beam and PrintNC-style rollers, two Y motors, and an 8-tool changer in Phase 2. The current CAD is the Fusion 360 model `Type_0_v3`.
Inspired by [Bootstrap Bill](https://github.com/Expatria-Technologies/bootstrap-bill-mill).

The project is in planning. Decisions are made one round of questions at a time.
