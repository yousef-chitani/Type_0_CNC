# Type 0 CNC

A DIY 3-axis CNC mill: fixed gantry and moving table, with a cast epoxy granite (EG) frame and an 8-tool changer.
Inspired by [Bootstrap Bill](https://github.com/Expatria-Technologies/bootstrap-bill-mill).

The project is in planning. Decisions are made one round of questions at a time.
